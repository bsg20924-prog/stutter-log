# 상황 시뮬레이션 배경음

여기에 아래 파일을 넣으면 **코드 수정 없이** 자동으로 붙는다.

| 파일 | 시나리오 | 분위기 |
|---|---|---|
| `cafe.mp3` | 주문 / 카페 | 카페 웅성거림, 컵 소리 |
| `office.mp3` | 자기소개 | 회의실 · 사무실 공기 |
| `phone.mp3` | 전화 예약 | 통화 회선 잡음 |

## 동작 방식

- 파일이 **없으면** 인트로의 「배경 소음 켜기」 토글이 **아예 표시되지 않는다.**
  눌러도 아무 일이 없는 스위치는 사용자에게 고장으로 읽히기 때문이다.
  콘솔 에러도 남기지 않는다 — 파일 없음은 예상된 상태이지 오류가 아니다.
- 하나라도 재생 가능하면 토글이 나타난다. 없는 키는 조용히 무음으로 처리된다.
- 기본 볼륨은 `AMBIENT_VOLUME = 0.15` (`src/utils/ambient.ts`).
  상대의 말(TTS)이 재생되는 동안에는 `0.05`로 자동으로 낮아진다 —
  배경음이 프롬프트를 덮으면 상황 연습이 아니라 방해가 된다.

## 파일 조건

- 형식: mp3 (Safari 포함 전 브라우저 지원)
- 길이: 30초 이상 권장 — 자동 반복(loop)되므로 이음매가 티 나지 않아야 한다
- 음량: 피크가 아니라 평균이 낮게. 코드에서 한 번 더 줄이지만 원본이 크면 클리핑이 생긴다
- **저작권**: 재배포 가능한 라이선스만 사용할 것 (CC0 등)
